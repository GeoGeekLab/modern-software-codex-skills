# Scope: course evidence versus local packaging

This repository does **not** reproduce the Fall 2026 course and does not claim that Stanford publishes an official Codex Skill pack.

## Three categories

1. **Official curriculum and assignments:** use the course website and instructor's assignments for claims about what CS146S actually teaches and evaluates.
2. **Historical course-linked sample files:** six pre-existing `original-SKILL.md` snapshots, attributed by the old repository to an October 1 Drive folder. Upstream file-by-file verification remains outstanding.
3. **Local Codex adaptation:** minimal frontmatter and path adjustments, UI files, installer, validation, and evaluation fixtures. These are not university course artifacts.

Do not promote a suggested Week 3 assignment topic (for example, security review or dependency upgrade) into a pre-existing course Skill. The assignment explicitly invites students to invent and validate **their own** skills.

Do not convert Week 1 agent internals, Week 2 MCP servers, Week 4 repository configurations, or Week 5 readiness reports into “official skills.” They are separate learning activities.

Do not claim that static fixtures demonstrate successful triggering. A live agent run and saved evidence are required for that statement.
